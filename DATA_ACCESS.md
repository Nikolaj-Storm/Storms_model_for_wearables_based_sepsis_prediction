# Data Access Guide

This project is built on **MIMIC-IV v3.1**, a de-identified critical-care
dataset that is **credentialed-access**. The data cannot be redistributed, so
it is not (and must never be) included in this repository. Anyone wanting to
fully reproduce the results must obtain their own access. This takes a few days
because of the required training and credentialing, but it is free.

## What you need

1. **A PhysioNet account** — https://physionet.org/register/
2. **CITI "Data or Specimens Only Research" training** — complete the course and
   upload the completion report to your PhysioNet profile. (The author's
   certificate is referenced in Appendix 1 of the thesis.)
3. **Sign the MIMIC-IV Data Use Agreement** on the dataset page and get
   credentialed:
   - MIMIC-IV: https://physionet.org/content/mimiciv/3.1/
4. **Access route — Google BigQuery (recommended, and what this code uses).**
   PhysioNet hosts MIMIC-IV as public-but-restricted BigQuery tables
   (`physionet-data.mimiciv_3_1_hosp.*`, `physionet-data.mimiciv_3_1_icu.*`).
   Request BigQuery access from your credentialed PhysioNet profile, then:
   - Create a Google Cloud project.
   - `gcloud auth application-default login`
   - The extraction scripts in `pipeline/1_extraction/` query these tables.

   Alternatively you can download the CSVs and load them into a local Postgres
   or DuckDB, but you would then need to adapt the Stage-1 SQL/loaders.

## Derived tables this project depends on

The thesis uses the official **`mimic-code`** concept derivations, not just the
raw tables. Before running Stage 1 you must build these into your own BigQuery
dataset (the code references a dataset named `YOUR_DERIVED_DATASET`):

- `sepsis3` — the Sepsis-3 onset labels (suspected infection + SOFA rise ≥ 2)
- `suspicion_of_infection` — antibiotic + culture timing
- `sofa`, plus the vital-sign concepts

Build them from the MIT-LCP repository:
https://github.com/MIT-LCP/mimic-code (the `mimic-iv/concepts` SQL).

A walkthrough of how the Sepsis-3 target was generated for this project is in
`docs/Sepsis3_Generation_Guide.docx`.

## Important: update the project/dataset identifiers

The extraction scripts contain the author's own Google Cloud project ID
(`YOUR_GCP_PROJECT`) and derived-dataset name (`YOUR_DERIVED_DATASET`). Replace these
with your own before running Stage 1. See the "Reproducibility notes" section of
`README.md` for the full list of hardcoded paths to adjust.

## Don't want to set up MIMIC-IV?

You can still run the modeling and figure code end-to-end on the included
**synthetic sample** (`data/synthetic/`, generated by
`tools/make_synthetic_data.py`). It mimics the real data's schema with random,
non-clinical values so you can verify the pipeline runs. The numbers it produces
are meaningless — it is a plumbing test, not a reproduction.
